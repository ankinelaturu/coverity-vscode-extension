# Coverity Report Helper (VS Code extension)

Local VS Code extension for loading a **Coverity text report** and navigating findings in an embedded C/C++ workspace—without Keil conversion, Coverity server access, or builds for basic viewing.

**Status:** Planning and documentation only (no extension source yet).
